## 🌟 Introduction

**Firefly AI Folder** is an intelligent file management tool powered by advanced AI technology. It integrates a local multi-modal AI engine to provide automatic tagging and summarization, semantics-based intelligent batch renaming, multi-dimensional virtual directories, and file deduplication & cleanup — with 100% of your data kept locally.

Unlike traditional file managers, Firefly brings AI understanding to your file system, transforming your files from cold data into knowledge assets with semantic meaning, quality scores, and multi-dimensional tags.

## ❓ FAQ

**Q: There are a lot of duplicate files in the computer and there is not enough hard disk space. What should I do?**

A: Use Firefly's "File Deduplication" and "File Cleanup" functions. The system automatically compares binary and AI image/text semantics to accurately find duplicate and highly similar files hidden in each folder, supporting safe space release with one click.

**Q: The photos exported by my phone/camera are all DSC_001.jpg. Looking for a file is like looking for a needle in a haystack?**

A: Use the "Smart Batch Rename" engine. AI automatically identifies the scene in the photo (such as "2026 Seaside Vacation") or the core title of the document, and renames files in batches with one click, saying goodbye to default meaningless file names.

**Q: The downloaded file cannot be opened — the extension is wrong?**

A: Firefly has built-in "real file format recognition and extension correction" that doesn't rely on file name suffixes. It directly verifies file header bytes to repair damaged or wrong extensions in seconds.

**Q: Worried about corporate documents or private files being uploaded to the cloud and leaking?**

A: Firefly uses a "100% local AI engine". All file analysis, OCR recognition, and semantic indexing are completed on your computer's local GPU/CPU. No bytes are ever uploaded to the Internet, so your privacy is absolutely safe.

## 🛠️ Technical Architecture

- **Core framework**: [Electron](https://www.electronjs.org/) + [Electron Vite](https://electron-vite.org/)
- **Frontend**: React 19 + TypeScript + Tailwind CSS + Zustand
- **AI engine**: [llama.cpp](https://github.com/ggml-org/llama.cpp) + LlamaIndex (local inference)
- **Database**: [Better-SQLite3](https://github.com/WiseLibs/better-sqlite3)
- **Native dependencies**: ffmpeg, sharp, textract, libreoffice-convert
- **Internationalization**: VoerkaI18n (source-as-copy mode)

## 📦 Build Instructions

If you want to build it yourself:

### Prerequisites

- **Node.js**: v22+
- **pnpm**: recommended
- **llama.cpp**: local AI inference environment

### Build Steps

```bash
# Install dependencies
pnpm install

# Start the development server
pnpm dev

# Package the application
pnpm build
pnpm package
```
