# Инструкция по Виртуальному Каталогу

## Обзор

`.VirtualDirectory` — это автоматически генерируемый виртуальный каталог данного приложения, используемый для отображения интеллектуально организованной структуры файлов. Он поддерживает однозначное соответствие с исходными файлами, но использует интеллектуальные соглашения об именовании.

## Назначение

Основная цель этого виртуального каталога — обеспечить многомерное управление файлами. Когда вас устраивает окончательный результат, вы можете скопировать файлы из этого каталога в любое место для следующей генерации виртуального каталога.

## Особенности

Файлы в виртуальном каталоге можно просто понимать как ссылки или псевдонимы файлов со следующими характеристиками:

1. Не занимает дополнительное физическое дисковое пространство
2. Использует те же блоки данных, что и исходные файлы
3. Изменения файлов будут синхронизироваться с исходными файлами
4. Удаление файлов не повлияет на исходные файлы
5. Если исходный файл удалён, этот файл фактически заменяет исходный файл и также должен быть удалён
