# 가상 디렉토리 설명

## 개요

`.VirtualDirectory`는 본 애플리케이션에 의해 자동으로 생성되는 가상 디렉토리로, 지능적으로 정리된 파일 구조를 표시하는 데 사용됩니다. 원본 파일과 1:1 대응 관계를 유지하면서도 스마트한 명명 규칙을 사용합니다.

## 목적

이 가상 디렉토리의 주요 목적은 다차원 파일 관리를 가능하게 하는 것입니다. 최종 결과에 만족하면, 이 디렉토리 내의 파일을 다른 위치로 복사하여 다음 가상 디렉토리 생성을 수행할 수 있습니다.

## 특징

가상 디렉토리의 파일은 파일의 참조 또는 별칭으로 이해할 수 있으며, 다음과 같은 특징이 있습니다:

1. 추가적인 물리적 디스크 공간을 차지하지 않음
2. 원본 파일과 동일한 데이터 블록을 공유함
3. 파일에 대한 수정이 원본 파일에 동기화됨
4. 파일을 삭제해도 원본 파일에는 영향이 없음
5. 원본 파일을 삭제하면 이 파일이 원본 파일을 대체하게 되므로, 이 파일도 함께 삭제해야 함
